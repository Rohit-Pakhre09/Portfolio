## Quick Start
### 1. Clone
```bash
git clone <your-repository-url>
cd portfolio
```

### 2. Install dependencies
```bash
pnpm install
```

### 3. Set environment variables
Create `.env.local`:

```env
NEXT_PUBLIC_SITE_URL=https://rohit-pakhre-portfolio.vercel.app
NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_service_id
NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_template_id
NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_public_key
NEXT_PUBLIC_EMAILJS_TO_NAME=Rohit
```

### 4. Run locally
```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment Variables
| Variable | Required | Purpose |
| --- | --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Recommended | Sets canonical base URL for metadata/Open Graph links. |
| `NEXT_PUBLIC_EMAILJS_SERVICE_ID` | Yes (for contact form) | EmailJS service identifier. |
| `NEXT_PUBLIC_EMAILJS_TEMPLATE_ID` | Yes (for contact form) | EmailJS template identifier. |
| `NEXT_PUBLIC_EMAILJS_PUBLIC_KEY` | Yes (for contact form) | EmailJS public key used by client-side request. |
| `NEXT_PUBLIC_EMAILJS_TO_NAME` | Optional | Receiver display name in EmailJS template. |
